# Paw Beauty Grooming — сайт грумінг-салону (Чернівці)

Статичний сайт без збірки: HTML + CSS + JS. Перенесено з Tilda (pawbeauty.tilda.ws).

## Структура

```
index.html        головна (лендинг, 16 блоків)
privacy.html      політика конфіденційності (чернетка)
offer.html        публічна оферта (чернетка)
404.html          сторінка «не знайдено»
assets/css/       стилі
assets/js/        анімації, калькулятор, форми
assets/img/       фото (стиснуті, 50–180 КБ)
```

## Як опублікувати на GitHub Pages

1. Створіть репозиторій на GitHub (наприклад `paw-beauty`).
2. Завантажте вміст папки `site` у корінь репозиторію.
3. Settings → Pages → Source: `Deploy from a branch`, гілка `main`, папка `/ (root)`.
4. За 1–2 хвилини сайт з'явиться за адресою `https://<логін>.github.io/paw-beauty/`.
5. Власний домен: Settings → Pages → Custom domain, у реєстратора додайте записи
   A на IP GitHub Pages і CNAME `www` → `<логін>.github.io`. Увімкніть «Enforce HTTPS».

## Заявки з форм

GitHub Pages не має сервера, тому заявки треба надсилати в сторонній сервіс.
Вкажіть адресу в `assets/js/main.js` → `CONFIG.endpoint`:

- **Formspree** або **Web3Forms**: безкоштовно, заявки на пошту.
- **Telegram**: Google Apps Script, який приймає POST і пересилає в бот.

Поки `endpoint` порожній, форма працює в демо-режимі (заявка лише в консоль браузера).

## Що замінити перед запуском

- Адреса салону, графік, паркування (позначено `[адреса салону]`).
- Посилання на Telegram, Instagram, Google-відгуки (зараз заглушки).
- Ціни на тримінг і SPA, коефіцієнти калькулятора (`PRICES` у `main.js`).
- Відгуки: зараз приклади тексту, потрібні справжні з посиланням на джерело.
- Фото «до/після» і команди: замінити на реальні фото салону.
- ФОП, email, тексти політики та оферти.
